# Alma Salinas · Peluquería & Belleza

Web demo de una peluquería y centro de belleza. Alma Salinas es un negocio ficticio: los datos de contacto, la dirección y las reseñas son de ejemplo.

🌐 **Demo en vivo:** https://sheisdigitalab.github.io/alma-salinas-web/

## Stack
HTML + CSS + JavaScript vanilla. Sin frameworks ni build step.

## Estructura
- `index.html` — one-page con hero, servicios, sobre, galería, testimonios y contacto
- `styles.css` — estilos (paleta crema/blush/sage, tipografías Fraunces + Inter)
- `script.js` — parallax del hero, nav, reveal-on-scroll, menú móvil

## Features
- Diseño mobile-first y totalmente responsive
- Parallax sutil en el hero
- Schema.org LocalBusiness/HairSalon para SEO local
- Botón flotante de WhatsApp con safe-area en iOS
- Cumple `prefers-reduced-motion`
